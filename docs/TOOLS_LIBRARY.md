# OrthoSim — библиотека инструментов и план перехода на новый ПК

> **Статус:** планируемые установки; это **не** список уже установленных приложений.  
> **Начато:** 2026-11-08. Обновлять по мере проверки.  
> **Проект:** OrthoSim (Windows, Python, 3D-модели зубов, позднее КЛКТ и исследовательские задачи).

## Принципы отбора

- Сначала восстановить рабочую среду и проверяемую версию OrthoSim, затем устанавливать дополнительные ИИ-инструменты.
- Предпочитать бесплатные и локальные инструменты, если они решают задачу.
- Не устанавливать всё сразу: каждый инструмент должен иметь измеримую задачу и понятный способ удаления.
- Перед исполнением чужих скриптов и установкой агентных навыков — изучить исходники, зависимости, доступ к файлам и сети.
- Не хранить API-ключи, секреты, медицинские данные или персональные сведения в GitHub. Реальные клинические данные не использовать для тестов без отдельного контролируемого процесса.

| Python **3.12 x64** | Совместимая среда текущего OrthoSim; перед сменой версии проверить зависимости | https://www.python.org/downloads/ | `py -3.12 --version` |

| Windows GPU drivers | Корректная 3D-визуализация; брать только с официального сайта производителя GPU | — | Проверка отображения 3D-сцены |
| ChatGPT / Codex | Совместная разработка, анализ кода, тесты | https://openai.com/codex/ | Провести маленькую задачу в отдельной ветке |

### Библиотеки Python (через `requirements.txt`, не устанавливать вручную по одной)

- **PySide6** — десктопный интерфейс.
- **PyVista / VTK** — 3D-визуализация и работа с поверхностями.
- **NumPy** — матрицы и геометрические преобразования.
- Остальные версии зависимостей брать из файла `requirements.txt` текущего коммита OrthoSim, не из произвольного списка.

## D. ИИ-агенты и расширения — *кандидаты, пока НЕ устанавливать автоматически*

| Инструмент | Практическая польза | Решение | Ссылка |
|---|---|---|---|
| **DeepSeek Harness** | Локальная среда ИИ-агента: работа с кодом, файлами, тестами и инструментами | P2: испытать отдельно на копии проекта; developer preview, возможны несовместимые изменения | https://github.com/deepseek-ai/deepseek-harness |
| **Scientific Agent Skills** | Специализированные исследовательские навыки агентов | P2: сначала статический аудит исходников и разрешений; включать по одному | Ссылку закрепить после проверки точного upstream-репозитория |
| **AgentMemory** | Долговременный контекст разработки между сессиями | P2: подтвердить безопасность хранения и реальную пользу | Уточнить конкретную реализацию перед установкой |
| **Ollama** | Локальные LLM без облачного API на подходящем железе | P2: только после оценки RAM/VRAM нового ПК | https://ollama.com/ |
| **FreeLLMAPI** | Возможный альтернативный API-доступ | **Отложить** до оценки надёжности, лимитов, безопасности | Точный upstream проверить отдельно |
| **Delegator** | Делегирование задач агентам | **Отложить** — пока избыточно | Точный upstream проверить отдельно |
| **ScallopBot / CircleChat** | — | **Не устанавливать**: ранее исключены из плана | — |

### Минимальный критерий испытания DeepSeek Harness

1. Использовать отдельную копию репозитория и отдельный каталог для временных файлов.
2. Не предоставлять полные права к домашнему каталогу и сохранённым секретам; не запускать команды без проверки.
3. Дать ограниченную задачу: поправить тестовый дефект геометрии с запуском unit-тестов.
4. Сравнить результат с текущим процессом разработки: успешные тесты, количество ручных исправлений, API-расходы и затраченное время.
5. Встраивать в рабочий процесс только после успешных повторных тестов.

Официальные предупреждения: https://github.com/deepseek-ai/deepseek-harness/blob/master/SAFETY.md

## E. Порядок перехода на новый компьютер

- [ ] Проверить конфигурацию нового компьютера (Windows, GPU/VRAM, RAM, диск) и необходимость обновления драйверов.
- [ ] Убедиться, что код и резервные копии на старом компьютере актуальны.
- [ ] Проверить приватность рабочего GitHub-репозитория и доступ к нему; никаких секретов и данных пациентов.
- [ ] Установить Git, Python 3.12 x64 и VS Code.
- [ ] Клонировать OrthoSim, создать отдельный `.venv`, установить зависимости из `requirements.txt`.
- [ ] Запустить unit-тесты, затем вручную проверить GUI, импорт STL, трансформации и экспорт.
- [ ] Восстановить тестовую копию Restic-бэкапа и проверить её открытие.
- [ ] Переподключить ChatGPT/Codex и Desktop Commander только с необходимыми полномочиями.
- [ ] Решить, нужен ли 3D Slicer для ближайшей задачи.
- [ ] Только после этого тестировать DeepSeek Harness / Scientific Agent Skills в изоляции.
- [ ] Оценить возможность Ollama по спецификации нового компьютера.
