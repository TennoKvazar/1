# OrthoSim 0.1 — первая настольная версия

**Статус:** учебный 3D-редактор, а не медицинское изделие и не программа прогнозирования ортодонтического лечения.

## Что работает

- Демонстрационная условная зубная дуга из 14 отдельных объектов (не анатомическая модель).
- Импорт отдельных моделей `.stl`, `.ply`, `.obj` (по одной модели/зубу в файле).
- Выделение модели в списке.
- Смещения вдоль глобальных осей X/Y/Z с шагом в миллиметрах.
- Повороты вокруг центра выбранной модели на заданный угол.
- Сохранение и восстановление этапов внутри открытой сессии.
- Экспорт преобразованных STL-моделей и JSON с матрицами и этапами.

**Не работает пока:** выделение зубов из общего скана, чтение DICOM, сегментация корней,
совмещение КЛКТ и сканов, вычисление сил/моментов, коллизии, биологическое прогнозирование,
сохранение/открытие сессии как полноценного проекта.

## Установка на Windows 10/11 x64

1. Установи **Python 3.12.10 (64-bit)** с https://www.python.org/downloads/release/python-31210/ . При установке поставь флажок **Add python.exe to PATH**, если появится. Нужен установщик Python, а не исходный код.
2. Распакуй архив в папку `C:\OrthoSim` (не запускай файлы прямо из ZIP).
3. Дважды щёлкни `setup_windows.bat` и дождись сообщения `Setup complete`.
4. Дважды щёлкни `start_windows.bat`.
5. В окне программы нажми `Открыть демонстрационную модель`, выбери условный зуб и нажми `X +` или `Z −`.
6. `Сохранить этап в проекте` записывает текущие координаты в оперативную память программы. `Экспортировать текущие STL + JSON` сохраняет текущие сетки и JSON на диск.

Если в окне установки появится ошибка, скопируй полный текст ошибки. В PowerShell можно проверить Python командой `py -3.12 --version`.

## Команды, если нужны вручную (PowerShell)

```powershell
cd C:\OrthoSim
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

## Понятие «зуб» в первой версии

Для первой версии каждый зуб должен быть отдельным STL/PLY/OBJ-объектом. Если загрузить один файл с цельным зубным рядом, программа будет двигать весь этот ряд как единый объект. STL-файлы обычно не содержат метаданных о единицах измерения и ориентации: **перед импортом подготовь их в миллиметрах**. Координаты сохраняются в системе исходных файлов, регистрация разных сканов не выполняется.

## Клиническая безопасность и конфиденциальность

Не загружай персональные данные пациентов и непсевдонимизированные исследования в прототип. Не используй изменения STL как прогноз реального перемещения зубов, оценки анкоража или назначения силы/дуги. Для этого потребуются отдельная физическая модель, экспериментальная и клиническая валидация.

## Архитектура

- `app.py` — окно программы и просмотрщик (PySide6 + PyVista/VTK).
- `geometry.py` — матричные преобразования 3D-объектов.
- `test_geometry.py` — простые автотесты геометрических операций.
- `requirements.txt` — Python-зависимости.
